# Club Penguin Isla (fan theme) 🐧

Tema de colores inspirado en Club Penguin + un pingüino y su puffle que caminan por el Explorador mientras programas.

- **Click al pingüino** → dice una frase (configurable en `clubPenguin.messages`).
- **Click al puffle** → salta y te habla.
- **🎨** → personaliza color, sombrero, accesorio, nombre y color del puffle.
- Comandos: `Club Penguin: Personalizar pingüino`, `Club Penguin: Mostrar pingüino`, `Club Penguin: Activar tema de colores`.

Proyecto de fans, sin afiliación con Disney ni Club Penguin. Todo el arte es original.
